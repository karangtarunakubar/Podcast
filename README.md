# 🎙️ Studio Podcast & Livestream UI
> Official Web App Studio Podcast Karang Taruna Kutai Barat (`@KarangTarunaKutaiBarat`).

Aplikasi web studio podcast berbasis **Neumorphic UI** yang mendukung perekaman video lokal, integrasi livestream ke YouTube API, serta pengelolaan sistem *permission/authorization*.

## 🚀 Fitur Utama
- **⚡ Approve All Permissions:** Sekali klik untuk mengaktifkan Kamera, Mikrofon, dan Akun YouTube API.
- **📷 Media Monitor:** Preview kamera studio resolusi tinggi ($1280 \times 720$).
- **💾 Rekam Lokal:** Menyimpan hasil podcast secara otomatis dalam format `.webm`.
- **📡 YouTube Live Stream:** Integrasi status indikator siaran langsung.
- **📱 Fully Responsive:** Kompatibel dengan perangkat HP, Tablet, dan Desktop.
